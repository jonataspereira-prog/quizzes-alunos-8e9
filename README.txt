# Quiz Educativo Gamificado

Portal principal para os 16 quizzes do 8º e 9º ano.

## Estrutura sugerida

Coloque esta pasta junto das pastas dos seus quizzes:

quiz_educativo/
├── index.html
├── style.css
├── script.js
├── 8ano/
│   ├── portugues/
│   ├── matematica/
│   ├── ciencias/
│   ├── geografia/
│   ├── historia/
│   ├── ingles/
│   ├── arte/
│   └── educacao-fisica/
└── 9ano/
    ├── portugues/
    ├── matematica/
    ├── ciencias/
    ├── geografia/
    ├── historia/
    ├── ingles/
    ├── arte/
    └── educacao-fisica/

## IMPORTANTE

No arquivo `script.js`, altere os 16 caminhos do objeto `quizzes` para os caminhos
reais dos seus quizzes.

Se os quizzes estiverem publicados em sites separados, você pode usar a URL completa,
por exemplo:

"Matemática": "https://seusite.com/quiz-matematica-8"

Não é necessário alterar o HTML para trocar os links.
